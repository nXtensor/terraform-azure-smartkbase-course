# Terraform on Azure — SmartKBase course repository

Course files for **Terraform on Azure: Provision Real Infrastructure as Code**.

This repository currently includes the Section 03 lab. Later sections will add more SmartKBase stages, exercises, and checkpoints.

## Start here

1. Read `smartkbase/README.md`.
2. Work in `smartkbase/`.
3. If you get stuck, use `docs/checkpoints.md`.
4. Practise destroy only in `demos/s03-destroy-demo/`.

## Section 03 map

| Path | Purpose |
|---|---|
| `smartkbase/` | Evolving SmartKBase project. Ships empty of `.tf` files. |
| `checkpoints/section-03-start` | Pins and provider. You write `main.tf`. |
| `checkpoints/section-03-solution` | Finished S03 (`development` tag) |
| `demos/s03-first-rg/` | Copy of the Section 03 video demo (work in `smartkbase/`) |
| `demos/s03-destroy-demo/` | Disposable destroy demo |
| `exercises/ex03-first-rg/` | Exercise brief |

## Rule

One SmartKBase stack. Do not create a new toy project for each video.
