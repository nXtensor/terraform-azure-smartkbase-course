# Checkpoint: section-03-start

Known-good SmartKBase **code** at the beginning of Section 03.

This folder has version pins and the AzureRM provider block. It does **not** include `main.tf`. You write the resource group in the lecture.

## How to use it

1. Copy these files into `smartkbase/` (or work from a copy of this folder).
2. Replace the placeholder `subscription_id` in `providers.tf` with your sandbox subscription id.
3. Follow the SmartKBase README to add `main.tf` and run the workflow.

Do not apply a second, unrelated project. SmartKBase is one stack.
